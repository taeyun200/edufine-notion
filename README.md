# 예산 장부 전처리기

에듀파인에서 내려받은 예산 파일을 노션에 그대로 가져올 수 있는 CSV로 바꿉니다.

**→ https://taeyun200.github.io/edufine-notion/**

설치할 것도, 로그인할 것도 없습니다. 링크를 열고 파일을 놓으면 됩니다.

## 파일은 컴퓨터를 떠나지 않습니다

변환은 전부 브라우저 안에서 일어납니다. 서버로 보내지 않고, 어디에도 저장하지 않습니다.
학교 예산·집행 자료를 다루는 도구라서 이렇게 만들었습니다.

페이지를 한 번 저장해두면 인터넷 없이도 열립니다. 파일 하나로 끝나는 페이지입니다.

## 쓰는 법

1. 에듀파인에서 **세출예산집행현황목록** 또는 **품의목록**을 내려받습니다 (`.xls` · `.xlsx` 둘 다 됩니다)
2. 이 페이지에 파일을 놓습니다
3. 가져올 사업을 고릅니다
4. `CSV 내려받기` → 노션에서 `가져오기 → CSV`

노션 속성 설정과 수식은 페이지 아래 **노션에 넣는 법**에 적혀 있습니다.

## 합계를 대조합니다

세출예산 파일에는 맨 위에 `합 계` 줄이 있습니다. 전처리기는 항목 줄을 모두 더해
이 값과 맞는지 확인하고 화면에 보여 줍니다.

파일이 잘리거나 에듀파인 출력 형식이 바뀌면 **틀린 CSV가 멀쩡해 보이는 얼굴로 나옵니다.**
검산은 그것을 잡기 위한 장치입니다. 경고가 뜨면 그대로 쓰지 마세요.

## 고쳐 쓰기

이 저장소에는 빌드 결과(`index.html`)만 있습니다. 원본과 빌드 스크립트는
[notion-integration-agent](https://github.com/taeyun200/notion-integration-agent)의 `tools/`에 있습니다.

```
python tools/build.py --fetch     # SheetJS를 받아 페이지 안에 끼워 넣고 dist/ 생성
cp tools/dist/예산-전처리기.html  <이 저장소>/index.html
```

읽기에는 [SheetJS](https://sheetjs.com) (Apache-2.0)를 씁니다. `.xls`(BIFF8)를 읽어야 해서
mini 빌드가 아닌 full 빌드를 페이지 안에 넣었습니다.
